# Day 9 Lab - Ethics, Licensing & Security Basics

**Level 1: Basic | Individual | 20 min | Dev + QA, same task | Formal governance checkpoint**

## Checklist review (20 min)

Files: `seeded/output-1.js` ... `output-5.js` (a mix of Dev and QA artifacts; all credentials are fake).

```
# Context
This is a Copilot-generated authentication snippet.
# Task
Review it against our security checklist: hardcoded secrets, missing
input validation, weak crypto defaults, PII in logs.
# Requirements
List every finding with severity and the line it's on.
```

1. Run the checklist prompt against each of the 5 outputs.
2. Flag which have a licensing or security red flag (clean ones exist).
3. Cross-check against the answer key at the debrief.

## Written test

10 questions, pass mark 70% (hard gate for Level 1).

## Assignment

Read the org's AI usage policy (or the Guide's Security Considerations section) and submit one question or one real example from your own Day 1-8 work.

## Never paste into a prompt

Secrets, credentials, customer PII, proprietary algorithms.
