# Day 11 Lab - Advanced Prompt Engineering (Chained Prompts)

**Level 2: Intermediate | Individual | 20 min | Dev and QA variants**

Build a reusable 3-prompt chain where each response feeds the next. Start from `chain-template.md`.

1. Run step 1 and get the plan (Dev) or scenario list (QA).
2. Feed the ACTUAL output (not a rewrite) into step 2.
3. Feed the ACTUAL step 2 output into step 3.
4. Save the chain with `[BRACKETS]` so a teammate can reuse it.

## Assignment

Apply the chain to one real task in your own repo.

## Assessment: present the template (2 min each), peer feedback on reusability
