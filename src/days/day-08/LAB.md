# Day 8 Lab - Working Across Languages & Stacks

**Level 1: Basic | Individual | 20 min | Dev and QA variants**

## Dev: cross-language rewrite (20 min)

Source: `phone-validation.ts`.

```
# Context
This TypeScript function validates a phone number for a signup form.
# Task
Rewrite this same validation in [an unfamiliar language], keeping identical edge-case behavior.
# Requirements
- Same accepted/rejected formats
- Note any behavior you couldn't guarantee is identical
```

Find one thing Copilot got subtly wrong. Classify it: syntax, logic, or convention.

## QA: cross-framework test generation (20 min)

Scenario: `login-scenario.md`. Generate the test in a framework you do not normally use. Find one thing that is subtly wrong or non-idiomatic.

## Assignment

Short written reflection: where it helped, where it struggled, and why.

## Assessment: reflection reviewed for critical evaluation

Names a specific mistake, not "it worked fine". Distinguishes syntax vs logic vs convention.
