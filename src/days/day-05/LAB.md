# Day 5 Lab - Prompt Writing Fundamentals

**Level 1: Basic | Individual | 20 min | Dev and QA variants**

Rewrite 3 vague prompts into the Context / Task / Requirements / Additional Info template. Dev: feature prompts. QA: test-scenario prompts. Seed prompts and a worked example are in `vague-prompts.md`.

```
# Context
[What you're working on]
# Task
[What you want the AI to do]
# Requirements
- [Requirement 1]
- [Requirement 2]
# Additional Info
[Tech stack, constraints, preferences]
```

1. Pick a vague prompt ("make a login form", "write some tests").
2. Rewrite it with real specifics (use the prompt builder on the Day 5 page).
3. Run the vague and the rewritten versions and compare the outputs side by side.

## Assignment
2 rewritten prompts (before and after) from your own work.

## Assessment: prompt-quality rubric
Requirements has 2+ concrete bullets. Context names the real stack. The rewritten output is visibly more usable.
