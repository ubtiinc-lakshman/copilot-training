# Day 2 Lab - Environment Setup & Licensing Across IDEs

**Level 1: Basic | Individual | 20 min | Dev + QA, no split**

Goal: leave with a verified, working Copilot install on the IDE you actually use for real work.

## Task 1 - Install and verify (12 min)

1. Install the GitHub Copilot and GitHub Copilot Chat extensions (VS Code, JetBrains or Visual Studio).
2. Sign in with your GitHub account and wait for activation.
3. Open the model-selector dropdown and confirm it lists multiple models.

## Task 2 - Confirm the model responds (8 min)

Prompt: `Write a one-line function that returns the current UTC timestamp.`

1. Run it with the default model.
2. Switch models and run it again.
3. Note any difference. Paste one answer into `utc.js`.

## Assignment

Confirm Copilot is active on your primary work machine (not just the training sandbox) and submit the setup checklist (see the Day 2 page).

## Assessment: setup checklist sign-off

Facilitator verifies by screenshare or screenshot. No red X before moving on.
