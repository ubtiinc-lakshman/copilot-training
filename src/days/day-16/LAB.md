# Day 16 Lab - Copilot in PR & Code-Review Workflows

**Level 2: Intermediate | Individual | 20 min | Dev and QA variants**

Dev works on the app-code diff; QA works on the test-code half of the same `sample.diff`. Template: `PR_TEMPLATE.md`.

```
# Context
[paste the diff]
# Task
Draft a PR description: what changed, why, and how it was tested.
# Requirements
- Link the requirement/ticket
- List test evidence explicitly, don't just say "tested"
```

1. Draft the PR description.
2. Respond to the 2 seeded comments in `review-comments.md` with Copilot's help.
3. Evaluate: does each response resolve the concern, or just sound responsive?

## Assignment

One real PR, opened or updated, using Copilot for the description and at least one comment response.

## Assessment: PR-quality checklist (clarity, linked requirement, test evidence)
