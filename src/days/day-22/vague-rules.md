# Rules that do NOT belong in an instructions file (not checkable against a live suggestion)

- Write good code.
- Follow best practices.
- Keep the code clean and readable.
- Make sure tests are high quality.
- Use a modern approach.

Rewrite each one into something a reviewer can check on a single suggestion. For example:
"Write good code" becomes "Functions are 40 lines or fewer and take at most 4 parameters".
